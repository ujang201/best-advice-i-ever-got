# The Best Advice I Ever Got

One sentence, up to 200 characters, on the best advice I ever received — judged pairwise by a judge model for the most lived truth.

## Entry

> The night I lost my first job, my father said: never make a permanent decision on a temporary feeling — it has saved me more times than I can count.

A real moment, a real voice: my father, the night I lost my first job, and a line I have carried ever since — never let a feeling that will pass decide something that will last.

## How it works

`main.ts` is a small deterministic Node program (no randomness, clock, network, or input). It writes that single sentence (148 characters) to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).

```sh
node main.ts
cat /output/entry.txt
```

## Files

- `main.ts` — the entry program
- `prompt.txt` — the build prompt
